## How each step runs

- Each step starts with a test that fails at its seam, in the same commit as its code. A test file that spawns tsc or TLC takes `heavyTestTimeout`.
- The `## Domain and effects` block records this brief. Step 5 put `cap TypeCheck [fs-read, fs-write, spawn] @ src/astack/domain/witness-run.ts: typeCheck(write)` in the card.

- `witnessSource` is pure, and the async `typeCheck` gives a promise of a Result. So the flow is a plain call with no monad law.
- L1 and L2 carry DB1 and L3 a write cap, so each gives R3. Step 1 parses this grammar, and `|` joins the caps of a row and the names of Errs.

```grammar
context <Ctx>    plan: one card context
context <Ctx> [shared] : <glob>, ...    card only
agg  <Agg> @ <module>: <State>[, <Cmd> -> <Event>]
inv  <Id> <Agg>: <one-line invariant>
cap  <Cap> [<class>, ...] @ <port path>: <op>(read|write), ...
pure <glob>    card only
step <name> : <A> -> <Out>
flow <name> = <step> >=> <step> ...
law  <Id> <InvId>|<Cap> <property>   check: tsc | prop <control-id> | tla <Model>.<Invariant>
map  <CtxA> => <CtxB>: <translation>, eq <path equation>   check: prop <control-id>
abs  <module>: hides <rule>, callers <path> ..., deletion inline|spreads <n>, alt <option>
rung R<0-4>
A := void | Type   Type := Atom | Atom[] | (Type, ...)   Atom := <Name> | string | number | boolean | unknown
Out := Type | void | Eff<Row, Errs, Type | void>   Row := never | <Cap> | <Cap>.<op> | ...
Errs := never | <Name> | ...   class := fs-read | fs-write | spawn | network | env | clock | random
```
