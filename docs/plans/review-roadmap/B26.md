# Result gets map, andThen and all, and each claimed law runs as a property test on code

This block moves the law claims of the proof contract from a TLA+ model to tests of the real functions.
It gives the law part of the M4 demo. When a person breaks `andThen` by hand, `bun test tests/property` fails.

ADR 0017 records the rule, and ADR 0006 D2 gets a dated note.
