- Contract. The carrier is pure. The objects are `ScanInput`, `Scan`, `LexInput`, `LexResult` and `CommentUnit`, and each links to its symbol.
- The arrows are `scan : (string, boolean) -> Scan | undefined`, `lex : (string, LanguageId) -> LexResult` and `unitsOf : (string, LanguageId) -> CommentUnit[] | undefined`. Each is pure and has no effect.
- The language switch is the arrow `lex`. It picks the `jsx` flag from the language, calls `scan` and maps the result inline. It adds no helper, because that helper has one caller.
- The complete gate is the arrow `unitsOf`. It returns undefined when `complete` is false. Otherwise it calls `commentUnits` with the source again.
- So no two arrows compose with `o`, and `composites` is empty. Each of the eight laws is not applicable for that reason.
- The model has three actions. `Step` is one turn of the `scan` loop. `Fail` is a token that does not close. `Finish` is the map in `lex`.
- The model input is a bounded sequence of name, name word, operand keyword, dot, slash, close and comment tokens.
- `MemberNameIsValue` says that a slash after a dot and a word is a division. Without it, the hooks lose the comment after `obj.return / 2;`.
- `NameWordIsValue` says that a slash after `as`, `satisfies`, `keyof` or `let` is a division. Without it, the hooks lose the comment after `as / 2;`.
- `NoCommentInRegex` says that a regex after an operand keyword never yields a comment. Without it, the comment hook reports a false comment, as `export default /[//]/` gives today.
- `FailedScanIsIncomplete` says that a failed scan gives no comments and `complete` false. Without it, a caller reads the comments of a file that the scanner cannot read.
- The negative control drops the member name rule.
- CS-MEMBER maps to `MemberNameIsValue`, and CS-NAME maps to `NameWordIsValue`. CS-REGEX maps to `NoCommentInRegex`, and CS-INCOMPLETE maps to `FailedScanIsIncomplete`.
