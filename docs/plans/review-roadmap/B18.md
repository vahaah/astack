# Dead code and zero-use parts go, and a word budget gate stops text growth

This block removes the parts of astack that nobody uses and that nothing live depends on.
It gives the second part of the M1 demo.
The cut paths are gone, and the budget gate reports at most 141,500 skill words.

## Context

- The refocus research counted the use of each skill, agent and command in the Claude Code and Codex history of the last 30 days. Each count has a positive control.
- 11 skills have 0 use. They are wait-what, wizard, blast-radius, correct, create-verification-skill, maintain-verification-skill, to-spec, to-questionnaire, implement, implement-spec and triage.
- The researcher agent has 0 spawns. `astack orch` has 0 runs since the 0.2.0 install, and index D7 already removes it.
- `scripts/lib/migration.ts` serves the switch from the old agent-stack install, and 0 config dirs hold an old plugin id.
- `astack plan move` and `astack plan import` have 0 runs. The hook tools `codex` and `grok-build` act as an unknown tool.
- `src/astack/hook/cursor.ts` reads a legacy problems file that no writer ever made.
- `scripts/validate.ts` runs `claude plugin validate` again after `scripts/dist/external.ts` runs it, and it crashes when `claude` is missing.
- 61 skills hold 150,701 words, and no gate stops them from growing.

## Goal

Goal. The parts with zero measured use and no live dependent leave the repo, and a ratchet stops skill text from growing back.
Decision. Can the owner trust that astack ships only the parts that someone uses?
Done when. `git ls-files` over the cut paths prints nothing, and the budget gate reports at most 141,500 skill words. Today it reports 150,701.

## Scope

- In. The 11 skills, the researcher agent, the orch code, the migration module, `plan move`, `plan import`, the two hook tools, the legacy Cursor record and 3 dead types.
- In. The word budget gate with one cap for each skill and a total, and ADR 0013.
- In. One run of `claude plugin validate`, with a labelled SKIP when `claude` is missing.
- Out. The orch store data on the owner's disk. Its deletion is an owner gate.
- Out. The comment lexer merge (B25), the wrapper skill folds (B21 to B23), `plan export` and `plan drift` (B33).
- Out. `scripts/skill-load-report.ts` and `scripts/bench-pr-head.ts`, because no verifier examined them.
